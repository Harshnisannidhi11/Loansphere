# LoanSphere

A modern web-based loan management system designed to simplify loan applications, offers, payments, monitoring, and financial management.

## 🚀 Live Demo

[LoanSphere](https://loansphere-lime.vercel.app/)

## 📌 Features

- User registration and login
- Google authentication
- Role-based access
- Borrower dashboard
- Lender dashboard
- Analyst dashboard
- Admin dashboard
- Loan application management
- Loan offers and browsing
- Payment tracking
- Loan monitoring
- Financial reports
- Risk analysis
- Transaction monitoring
- User management
- Responsive UI
- Dark mode support

## 👥 User Roles

### Borrower
- Browse loan offers
- Apply for loans
- View applications
- Manage active loans
- Track payments

### Lender
- Create loan offers
- Review borrower applications
- Manage loan offers
- Track active loans and payments

### Analyst
- Analyze loans and transactions
- Generate financial reports
- Perform risk analysis

### Admin
- Manage users
- Monitor loans and transactions
- View system activity

## ⚙️ Installation

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## 🧪 Testing

Run the Playwright tests with:

```bash
npx playwright test
```

## 🔐 Environment Variables

Create a `.env` or `.env.production` file locally and configure the required environment variables.

Do not commit environment files containing sensitive credentials.
